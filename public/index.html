Como usar o Cupons em Lote

      

      
    

    

      Antes de começarPasso a passoPlanilha
      RestriçõesDepois do envioErros comunsDúvidas
    

    

      
O app cria vários cupons de uma vez na VTEX, cada um com o código que você escolher (por exemplo, mariasilva10), e liga todos à mesma promoção pela UTM.


      

        
Antes de começar

        
    
          
  1. Uma AppKey e um AppToken com acesso ao módulo de Promoções e Impostos (Rates and Benefits). Eles são gerados em Configurações da conta › Chaves de aplicação no Admin.
    2. 
          
  2. A promoção criada, com a condição de cupom/UTM usando o valor que você vai informar aqui (ex.: funcionario10). Cupom sem promoção ligada não dá erro, mas também não aplica desconto.
    3. 
          
  3. A lista de códigos em .xlsx, .csv ou .txt. Se não tiver uma, baixe a planilha de exemplo no passo 3.
    4. 
        

      


      

        
Passo a passo

        
1
Conexão VTEX. Preencha Account (o nome da loja, ex.: iotrussardi), AppKey e AppToken e clique em Testar conexão. Se aparecer "Conexão OK", pode seguir.

        
2
Vínculo com a promoção. Informe a utm_source (obrigatória) e, se a promoção usar, a utm_campaign. Todos os cupons do lote recebem esses valores. Em Restrições, decida se vai limitar o uso (veja abaixo).

        
3
Lista de cupons. Arraste o arquivo para a área de upload. O app acha sozinho a coluna dos códigos; se errar, escolha a coluna certa no seletor. Confira os números: Para enviar, Duplicados (enviados uma vez só) e Inválidos (ficam de fora).

        
4
Criar cupons. Recomendado: clique em Verificar se já existem antes. Depois, Criar cupons e confirme no segundo clique. Acompanhe a barra de progresso e o log; no fim, baixe o relatório.

        
Dica: na primeira vez com uma promoção nova, faça um teste com 2 ou 3 códigos, confira no Admin (Promoções › Cupons) e aplique um deles no checkout antes de subir a lista inteira.

      


      

        
Como montar a planilha

        
    
          
  • Um código por linha, de preferência numa coluna chamada Cupom.
    • 
          
  • Use só letras, números, hífen (-) e sublinhado (_). Sem espaços nem acentos.
    • 
          
  • Outras colunas (nome, cargo, loja) podem ficar; o app ignora e elas ajudam você a conferir.
    • 
          
  • Em .txt, basta um código por linha, sem cabeçalho.
    • 
          
  • O arquivo é lido no seu navegador: a planilha não é enviada para o servidor, só os códigos na hora de criar.
    • 
        

      


      

        
Restrições de uso

        
Funciona igual ao Admin da VTEX:

        
    
          
  • Desligado: cada cupom pode ser usado quantas vezes for preciso.
    • 
          
  • Ligado: você define quantas vezes cada cupom pode ser usado no total, na loja inteira. Se um pedido com o cupom for cancelado, o uso volta a ficar disponível.
    • 
        

        
A mesma regra vale para todos os cupons do lote. Para regras diferentes, separe em listas e rode uma vez para cada.

      


      

        
Depois do envio

        
    
          
  • Baixar relatório: CSV com cada código e o status (criado/atualizado, erro ou não enviado). Abre no Excel.
    • 
          
  • Se algum lote falhar, monte uma planilha só com os códigos com erro e rode de novo. Reenviar um código que já foi criado não duplica, só atualiza.
    • 
          
  • Para conferir, abra Promoções › Cupons no Admin e busque alguns códigos.
    • 
        

      


      

        
Erros comuns

        

          
MensagemO que fazer

          
HTTP 401AppKey ou AppToken errados. Copie de novo, sem espaços.

          
HTTP 403A chave não tem permissão em Promoções. Peça para incluir o recurso no perfil de acesso dela.

          
HTTP 404Account ou ambiente errado. Use só o nome da loja, sem https:// nem .com.br.

          
Account inválidoO campo aceita só letras, números e hífen.

          
Nenhum código nessa colunaEscolha outra coluna no seletor ou ajuste a opção de cabeçalho.

          
Tentativa falhou (429/5xx)A VTEX pediu calma. O app tenta de novo sozinho até 3 vezes; se persistir, diminua Cupons por requisição em Avançado.

        

      


      

        
Dúvidas frequentes

        
E se o código já existir na loja?
O app detecta os cupons que já existem e os corrige um a um com a UTM e as restrições configuradas agora (inclusive tirando o limite de uso, se o limite estiver desligado), em vez de dar erro. Use Verificar se já existem para ver quais seriam afetados antes de enviar.

        
Dá para apagar um cupom criado errado?
Não. A VTEX não exclui cupons, só arquiva, pelo Admin ou pela API, um de cada vez.

        
Existe limite de cupons?
Sim, a VTEX limita o número de cupons ativos por loja e recomenda reaproveitar cupons quando possível. Cupons arquivados não contam.

        
Minhas credenciais ficam salvas?
Não no servidor: elas vão junto de cada requisição e são repassadas direto para a VTEX. No seu navegador, só ficam guardadas se você marcar Lembrar chave e token neste PC. Em computador compartilhado, deixe desmarcado.

        
Como acompanho quanto cada cupom foi usado?
No Admin, em Promoções › Cupons, cada cupom mostra quantas vezes foi usado. Para faturamento por cupom, use os pedidos (OMS), onde o código fica registrado em cada pedido.
